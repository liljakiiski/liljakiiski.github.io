Honeycomb Game Console


C++ Arduino CAD Electrical

Overview

As a video games enjoyer I thought it would be fun to design a miniature game console myself. I got to practice my CAD skills by custom designing the case, brush up on my Arduino abilities, and have some fun programming a game for it.

Case Design

I designed the case on Onshape, and went through a couple different design iterations, fixing sizing issues between prints. Overall I was going for a "streched honeybomb" look (essentially just a hexagon), and I'd say the final design accomplishes that well enough.
(🔗 CAD available here),

Software

I decided to program a basic asteroid shooting game for the console, that takes an angle from the joystick and shoots a bullet at the click of the button. Each asteroid would disappear upon impact, and the program would count the number of asteroids hit. I managed to get a high score of 83 when testing it out.

Electronics / Wiring

The wiring design was done using Fritzing. Note that the following diagram does not include the LCD display, but that’s essentially just attached on top of the Arduino (connects to all the back pins). Actually wiring up the case didn't take a long time, although fitting the wires neatly into the case took a few tries.
