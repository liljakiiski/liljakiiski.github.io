Line Follower Robot


Python Linux Raspberry Pi Electrical Robotics LEGO

Overview

As the final project for ENGR161 we were tasked to create a LEGO robot to hold and deploy cargo whilst following a black line on a white terrain. My team came up with a solution using 2 grove hall line finder sensors, a color sensor, and an IMU, and was successfully able to follow the line to the finish and deploy cargo on detection of a magnet.

Physical Design

The robot uses a back-wheel drive with added gears for increased torque for the drivetrain, in order to be able to drive over hilly obstacles. The main frame and cargo systems stayed relatively similar throughout the process, with line sensors in the front of the robot, the pi in the center, and the battery at the front in order to balance out the cargo.

Software

I used python alongside the Grove Hall sensors and libraries to write the code for the robot. The code integrated several different functions in one main loop, making it so that the robot would travel along the line, correcting its movement based on the feedback from a left, right, and color sensor, and drop the cargo on detection of a magnet via the IMU sensor.

Conclusions

In testing the robot had fluctuating performance, the sensors needed to constantly be re-tuned and new constants found to create smooth movement. However, the robot performed well in the final demonstration, able to perform multiple runs with separate checkpoints and deployed cargo with high accuracy (inside 1cm of the center).
