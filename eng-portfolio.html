Physical 4-Bit Carry-Save Adder

❮ ❯
SystemVerilog Electrical Digital Circuits Breadboard

As a final project for my Intro to SoCET class, my team decided to make a 4-bit Carry Save Adder (CSA). A CSA is a digital circuit that computes the sum of (in this case: three) or more binary numbers by utilizing four full adders.

ENGR161 Line Follower Robot

❮ ❯
Python Linux Raspberry Pi Electrical Robotics LEGO
As the final project for ENGR161 we were tasked to create a LEGO robot to hold and deploy cargo whilst following a black line on a white terrain. My team came up with a solution using 2 grove hall line finder sensors, a color sensor, and an IMU, and was successfully able to follow the line to the finish and deploy cargo on detection of a magnet.

ENGR162 Maze Traversing Robot

❮ ❯
Python Linux Raspberry Pi Electrical Robotics LEGO
As the final project for ENGR162 my team was tasked to create a LEGO robot to autonomously navigate a walled maze, while avoiding hazards (magnetic and IR beacons). My team created a robot using three ultrasonic sensors (at the front, and left/right sides), alongside an IMU and IR sensor for hazard detection. I also worked on developing and fine-tuning a PID algorithm to optimize the robot’s turning and staying on course. I also worked on creating a custom cargo container with CAD.

IR Remote Controlled Car

❮ ❯
C++ Arduino Robotics
I programmed a custom Arduino-based driving system for a miniature robot car, to drive left/right/forwards/backwards based on input from an IR transmitter. I also implemented PID control to smoothen the robot’s driving. The project used an Arduino MEGA, a DC motor controller, and IR receiver and transmitter, and assorted wires.
